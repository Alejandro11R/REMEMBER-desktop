# Guía de Contribución y Reportes (`CONTRIBUTING.md`)

¡Gracias por ayudarnos a mejorar **REMEMBER** durante su fase Beta!

Dado que este repositorio actúa como el **canal comunitario público** de REMEMBER, puedes contribuir de las siguientes maneras:

## 1. Reportar Errores (Bugs)
Antes de crear un nuevo Issue, revisa si el problema ya fue reportado en la pestaña [Issues](https://github.com/Alejandro11R/REMEMBER-desktop/issues).
Al abrir un reporte:
- Usa la plantilla **Reporte de Error / Bug Report**.
- Indica tu sistema operativo (Windows 10/11, distribución de Linux o navegador Web) y la versión de la app (`v0.1.3 Beta`).
- Especifica si estabas usando la aplicación en **Modo Invitado (Local)** o con **Sesión Iniciada (Sincronización activa)**.
- **Privacidad:** Nunca subas archivos de base de datos (`.db`, `.sqlite`), variables de entorno (`.env`) ni tokens de sesión.

## 2. Proponer Mejoras (Feature Requests)
- Usa la plantilla **Sugerencia de Función / Feature Request**.
- Describe qué problema de estudio o flujo académico buscas resolver y cómo te gustaría que funcionara en REMEMBER.

## 3. Vulnerabilidades de Seguridad
- **No publiques fallos de seguridad en Issues públicos.** Sigue el procedimiento descrito en [`SECURITY.md`](./SECURITY.md) escribiendo a `hola@isremember.com`.
